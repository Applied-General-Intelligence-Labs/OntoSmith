Rebuild the graph

Adding files doesn't change the graph until you rebuild. A rebuild processes every document in the library and then replaces the graph in Neo4j, so its cost grows with the library.

Served by ontosmith serve --library. Documents are files in the library folder; every build is a batch you can inspect with ontosmith batch status.
